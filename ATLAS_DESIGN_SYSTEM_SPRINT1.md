# Atlas Design System — Sprint 1

## Added
- Shared `design/atlas-shell.css`
- Shared `js/atlas-shell.js`
- Dark Atlas ambient background across Home, Browse Pets, Pet Profile, Community and Messages
- Unified glass header styling
- Persistent **Return to Atlas** gateway
- Atlas navigation item in the shared header
- Smooth same-site page travel overlay
- Context-aware transition messages
- Mobile and reduced-motion support

## Installation
Copy `index.html`, `pages/`, `design/atlas-shell.css` and `js/atlas-shell.js` into the project, preserving folders.

## Rollback
Restore the previous five HTML files and remove `design/atlas-shell.css` plus `js/atlas-shell.js`.

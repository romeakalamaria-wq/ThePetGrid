# ThePetGrid Atlas v0.9.2 — Living Stories

## Added
- Story text inside the existing pet focus card.
- Country flag and relative joined time.
- “Explore another story” discovery action.
- Smart next-story ranking: same city, then country, then pet type, while preferring unseen pets.
- Cinematic camera transition between pet stories.
- Keyboard shortcut: press N while the story card is open.

## Install
Copy the `pages`, `js`, and `css` folders into the project root and replace the matching files.

## Test
1. Open the World Experience.
2. Select a pet light.
3. Confirm the story, country flag, and joined time appear.
4. Select “Explore another story”.
5. Confirm the camera moves and a different pet story appears.

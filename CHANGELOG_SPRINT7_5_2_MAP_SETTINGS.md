# Sprint 7.5.2 — Visible Map Settings

- Added a clearly visible **Map settings / Geoapify key** button in the map sidebar.
- Added a modal for adding, showing, saving and removing the Geoapify API key.
- The key is stored in browser localStorage under `tpg:geoapify-api-key`.
- Added validation, masked-key status and keyboard support (Enter / Escape).
- No npm, CLI or Edge Functions are required.

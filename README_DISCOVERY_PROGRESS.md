# Atlas v0.9.3 — Discovery Progress Step 1

Adds persistent Atlas journey tracking, new/visited story status, smarter story discovery, and milestone achievements.

## Install
Copy the `pages`, `js`, and `css` folders into the project root and replace the existing files.

## Test
1. Open World Experience.
2. Click several pet lights.
3. Use Explore another story.
4. Refresh the page and confirm the counters remain.
5. Use Reset only if you want to clear local progress.

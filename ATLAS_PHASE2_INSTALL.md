# ThePetGrid World Experience — Phase 2: Planet Alive

## Installation
1. Copy the contents of this `ThePetGrid1` folder over the current project folder.
2. Replace files when Windows asks.
3. From the project root run:

```powershell
git add "pages/world-experience.html" "css/world-experience.css" "js/world-experience.js" "CHANGELOG_WORLD_EXPERIENCE_PHASE2_PLANET_ALIVE.md" "ATLAS_PHASE2_INSTALL.md"
git commit -m "World Experience Phase 2 Planet Alive"
git push origin main
```

4. After Vercel deploys, open:

`https://the-pet-grid.vercel.app/pages/world-experience.html`

## Safety

# Atlas v0.9.4 — World Events Engine Step 1

Adds a compact live events timeline to the World Experience.

## Included
- Shared event model for new pet, adoption, lost, birthday, memorial and milestone events
- Seeded events from the current pet dataset
- Realtime new-pet events from Supabase inserts
- Click an event to focus its pet and open the story card
- Collapsible responsive events panel

## Install
Copy `pages`, `js`, and `css` into the project root and replace the existing files.

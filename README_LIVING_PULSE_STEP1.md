# ThePetGrid Atlas v0.9.2 — Living Pulse Engine (Step 1)

## Added
- Random live pet pulse every 8–12 seconds
- Temporary bright highlight and expanding ring
- Live activity notification with pet and location
- Gentle camera drift only while the user is idle
- Interaction guard: no automatic camera movement while the user explores, a pet card is open, or a country is selected
- Selected-country pulses stay inside that country
- Reuses the existing Globe.GL points/rings layers for low overhead

## Install
Replace `js/world-experience.js`. The HTML and CSS are included unchanged for safe full-folder replacement.

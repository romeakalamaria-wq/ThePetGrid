# Sprint 9.4.1 — Persistent Lost Pet Notification Center

## Added

- Persistent bell icon in the global header.
- Unread counter for nearby lost pet alerts.
- Notification history with the latest 50 alerts.
- Direct links from each notification to the report and map location.
- Read/unread state controlled by the user.
- `Mark all as read` action.
- Resolved indicator when a lost pet is marked as found.
- Realtime updates for new alerts, read state, and report resolution.

## Fixed

- Nearby alerts are no longer marked as read automatically when the temporary toast appears.
- A missed toast remains visible in the notification center until the user opens it.

## Database

No additional SQL is required when Sprint 9.4 SQL has already been installed.
